# BECHIR STOCK — بشير ستوك

تطبيق Android شخصي عربي لإدارة مخزون الفريب والمبيعات. نسخة أولية قيد البناء.

- شراء بالقطعة أو بالبالة، مع توزيع تكلفة البالة بالتساوي.
- حفظ المنتجات والمبيعات محليًا دون إنترنت.
- لا تتضمن هذه النسخة إزالة خلفية الصور؛ ستضاف بعد اختبار نموذج مناسب.

يُبنى APK تجريبيًا عبر GitHub Actions.
